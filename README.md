# MAG Analysis Pipeline

**Metagenome-Assembled Genome (MAG) analysis pipeline for Day 4 of the Omics Case Study Week.**

## 🔬 Pipeline Overview

```
raw reads → fastp QC → MEGAHIT assembly → Binning (MetaBAT2/MaxBin2/CONCOCT)
                                                                      ↓
                                                    DAS Tool dereplication
                                                                      ↓
                              GTDB-Tk taxonomy ← CheckM quality assessment
                                                      ↓
                               CoverM abundance ← Prokka annotation
```

## 📋 Steps

| # | Step | Tool | Description |
|---|------|------|-------------|
| 1 | QC | fastp | Filter low-quality reads, remove adapters |
| 2 | Assembly | MEGAHIT | Assemble filtered reads into contigs |
| 3a | Binning | MetaBAT2 | Coverage-based binning |
| 3b | Binning | MaxBin2 | Marker gene binning |
| 3c | Binning | CONCOCT | NMF-based binning |
| 4 | Dereplication | DAS Tool | Combine and dereplicate bins |
| 5 | Quality | CheckM | Completeness + contamination (MIMAG standard) |
| 6 | Taxonomy | GTDB-Tk | Genome-based taxonomy classification |
| 7 | Annotation | Prokka | Gene prediction and annotation |
| 8 | Abundance | CoverM | MAG abundance estimation |

## 📦 MIMAG Quality Standards

| Quality | Completeness | Contamination |
|---------|-------------|---------------|
| **High (HQ)** | ≥ 90% | < 5% |
| **Medium (MQ)** | ≥ 50% | < 10% |
| **Low (LQ)** | ≥ 50% | < 5% |

## 🚀 Quick Start

### 1. Install dependencies

```bash
# Clone the repo
git clone https://github.com/nullvoid42/metagenomics-mag-pipeline.git
cd metagenomics-mag-pipeline

# Create conda environment
conda env create -f envs/environment.yaml
conda activate mag-pipeline

# Install GTDB-Tk reference data (once, ~5GB)
download_gtdbtk参考数据.sh   # or: gtdbtk download_refdata --db_dir $GTDBTK_DATA_PATH
```

### 2. Download test data

```bash
# Option A: Download CAMII SIM001 simulated soil metagenome (recommended, ground truth known)
./bin/download_test_data.sh cami

# Option B: Download SRA human gut metagenome ERR011100
./bin/download_test_data.sh sra

# Option C: Use your own data — set paths in config/config.yaml
```

### 3. Configure

Edit `config/config.yaml` to set:
- Sample names and read paths
- Number of threads
- Cluster parameters
- Output directories

### 4. Run the pipeline

```bash
# Dry run (validate workflow)
snakemake -n

# Run locally (small test)
snakemake --use-conda -j 8

# Run on HPC cluster (Slurm)
snakemake --use-conda --cluster "sbatch -n 1 -t {params.runtime} --cpus-per-task {threads}" -j 64

# Run specific step
snakemake --use-conda 05_checkm
```

## ⚙️ Configuration

Key config options in `config/config.yaml`:

```yaml
project:
  name: "mag_pipeline"
  samples: ["sample_A", "sample_B"]  # Add your sample names

data:
  reads_dir: "data/reads"
  adapters: ""  # Auto-detect or provide FASTA

assembly:
  tool: "megahit"
  min_contig_len: 1500  # Minimum contig length for binning

binners:
  metabat2: true
  maxbin2: true
  concoct: true

dastool:
  score_thresh: 0.5
  search_engine: "blast"

checkm:
  lineage_wf: true  # Use lineage-specific marker set

gtdbtk:
  genome_path: "results/04_dastool/dereplicated_bins"
  out_path: "results/06_gtdbtk"

prokka:
  kingdom: "Bacteria"
  add_genes: true

coverm:
  method: "coverage"
  min_read_identity: 0.95
```
